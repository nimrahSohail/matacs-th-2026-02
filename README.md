## The design in short

A reviewer uploads proposals and picks a category. **AI reads each proposal and extracts facts, each backed by an exact quote. It does not score.** Plain code checks those quotes against the document, applies the admin's mandatory gates and scoring formulas, and produces a ranked list with a reason for every position. Anything doubtful is **flagged** for a person instead of guessed. A person reviews, can override with a reason, and makes the award. Every step is logged.

Result on the sample set: **A first (75.6), E second (62.5)**. C is **flagged** because it hides an instruction aimed at automated reviewers. D is **flagged** because it has no committed timeline. B is **ineligible** because its licence belongs to an unconfirmed subcontractor.

## How I used AI tools

I used Claude Code (Claude Opus 5.5) as the main builder: I gave it the brief and it drafted the design, the write up, the extraction prompt, the diagram and the Node.js prototype. I did not accept its first output as is: running the prototype and its tests (`node run.js`, `node --test`) exposed two errors that were then corrected. Totals were being added up from rounded per criterion scores (E showed 62.6 instead of 62.5), which would make scores drift from what the formulas say. The first dependency setup also used a Zod version that the SDK's structured output helper does not support, so live mode would have crashed. This is why the design checks AI output with code instead of trusting it.

## Notes

- The proposal text from the brief is **not** copied into this repository. The prototype's offline fixtures store only the extracted values. To run the AI step for real, paste the sample text into local, git-ignored files (see [prototype/README.md](prototype/README.md)).
- All companies and figures are the fictional samples from the brief.
- Quick check: `cd prototype && node run.js` prints the ranking and `node --test` runs the 12 tests (Node 21+, no install needed).
- Live AI mode (`node run.js --live`) is written but has not been run against the API, because no API key was used for this submission. The ranking comes from the offline fixtures, scored by the same code.
- Assumptions made where the brief was silent (scoring formulas, the 5-year window, what counts as a "named" lead) are listed at the top of [WRITEUP.md](WRITEUP.md).
